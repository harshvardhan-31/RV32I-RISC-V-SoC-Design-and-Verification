# Phase 2 Simulation Reports

This directory stores real execution logs produced by Icarus Verilog (`iverilog` / `vvp`) when running Phase 2 testbenches.

In adherence to the repository engineering principles:
- No log is fabricated, estimated, or hand-edited.
- Reports are only committed when generated by an actual simulation tool run.

## How to generate simulation reports

Run:
```bash
./scripts/run_phase2_sim.sh all
```
or on Windows with PowerShell:
```powershell
.\scripts\run_phase2_sim.ps1 -TargetTest all
```

Each testbench will write its complete output log to:
- `tb_alu.log`
- `tb_register_file.log`
- `tb_instruction_decoder.log`
- `tb_immediate_generator.log`
- `tb_control_unit.log`
- `tb_pipeline_registers.log`
- `tb_load_store_unit.log`
- `tb_cpu_core.log`
